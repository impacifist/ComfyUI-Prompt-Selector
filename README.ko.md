# ComfyUI Prompt Selector

자주 쓰는 프롬프트를 ComfyUI 노드 안에서 저장하고, 검색해서 다시 사용하는 프롬프트 라이브러리입니다. 같은 워크플로의 여러 노드가 저장 목록을 공유하면서 각자 다른 프롬프트를 선택할 수 있습니다.

[English](README.md)

v1.1.0: 목록창과 프롬프트 입력창 아래의 손잡이를 드래그해 높이를 각각 조절할 수 있습니다.

![공개 예제로 구성한 Prompt Selector](docs/images/prompt-library.png)


## 주요 기능

- **저장은 새 항목 추가, 수정은 기존 항목 변경.** 새 프롬프트 버튼을 먼저 누를 필요가 없습니다. 같은 이름은 번호를 붙여 구분합니다.
- 이름·태그·본문 검색과 즐겨찾기 필터.
- 등록순, 이름 오름차순(A–Z / 가–하), 내림차순 정렬.
- 목록창·입력창 높이를 개별 조절하고 노드별로 워크플로에 저장.
- 같은 워크플로의 Prompt Selector끼리 저장 목록 공유. 선택 항목과 미저장 편집은 노드별로 유지합니다.
- 복제, 삭제, 마지막 삭제 항목 복구.
- JSON 가져오기·내보내기와 현재 텍스트 복사.
- 현재 편집 내용과 이름을 각각 `STRING`으로 출력. 별도 모델이나 API 계정, 추가 Python 패키지가 필요하지 않습니다.

## 설치

저장소 ZIP을 내려받아 다음 구조로 압축을 풉니다.

```text
ComfyUI/custom_nodes/ComfyUI-Prompt-Selector/
├── __init__.py
└── web/
```

ComfyUI를 재시작하고 브라우저를 새로고침합니다. 노드 메뉴의 **Prompt Selector → Prompt Selector**를 추가하면 됩니다. 설치 형태별 경로는 [ComfyUI 공식 안내](https://docs.comfy.org/installation/install_custom_node)를 참고하세요.

## 기본 사용법

1. 이름, 쉼표로 구분한 태그, 프롬프트를 입력합니다.
2. **저장**을 누르면 현재 내용이 새 항목으로 추가됩니다.
3. 기존 항목을 고치려면 목록에서 선택하고 편집한 뒤 **수정**을 누릅니다.
4. `prompt` 출력을 텍스트 입력에 연결합니다. 예를 들어 CLIP Text Encode의 텍스트 위젯을 입력으로 변환한 뒤 연결할 수 있습니다. `name`은 현재 편집 중인 이름입니다.
5. 라이브러리를 보관하려면 ComfyUI에서 **워크플로도 저장**합니다.

[기본 예제 워크플로](examples/basic-prompt-selector.json)는 내장 PreviewAny 노드로 문자열 출력을 확인합니다. 생성 모델 없이 실행할 수 있습니다. [공개 예제 프롬프트](presets/starter-prompts.json)를 **JSON 가져오기**로 불러오면 다른 워크플로에서도 예제를 사용할 수 있습니다.

| 버튼 | 하는 일 |
| --- | --- |
| 저장 | 편집 내용을 새 항목으로 추가 |
| 수정 | 선택한 기존 항목을 편집 내용으로 변경 |
| 새 프롬프트 | 빈 편집 화면으로 시작 |
| 복제 | 현재 프롬프트를 복제 |
| 목록 정렬 | 목록 표시 순서 변경 |
| 즐겨찾기 / 상단 ★ | 항목을 즐겨찾기로 지정 / 즐겨찾기만 표시 |
| 삭제 / 삭제 복구 | 항목 삭제 / 마지막 삭제 되돌리기 |
| JSON 내보내기 / 가져오기 | 라이브러리 내보내기 / 가져온 항목 추가 |
| 텍스트 복사 | 현재 프롬프트 복사 |

편집기 안에서 Ctrl/Cmd+S는 **새 항목 저장**입니다. 기존 항목 변경은 **수정**을 사용하세요. ComfyUI 워크플로 저장과는 별도입니다.

목록창과 입력창 바로 아래의 가로 손잡이를 위아래로 드래그하면 높이를 조절할 수 있습니다. 손잡이를 더블클릭하면 기본 높이로 돌아갑니다. 손잡이에 키보드 포커스를 둔 상태에서는 위·아래 방향키로 조절하고 Home으로 초기화할 수 있습니다. 높이는 노드별로 워크플로에 저장되며 다른 노드의 설정에는 영향을 주지 않습니다. 영역을 크게 늘려 노드 안에 들어가지 않으면 내부를 스크롤하거나 노드 자체를 늘리세요. 입력창을 개별 조절하기 전과 초기화 후에는 기존처럼 노드 높이에 맞춰 자동으로 늘어납니다.

## 이렇게 쓰면 편합니다

카메라 움직임, 조명, 스타일, 네거티브 프롬프트를 이름과 태그로 정리해 두면 반복해서 찾고 붙여 넣는 작업을 줄일 수 있습니다. 원본을 남기고 변형을 비교하려면 **저장**, 원본의 오탈자나 표현을 고치려면 **수정**을 사용합니다.

![같은 목록에서 서로 다른 항목을 선택한 두 노드](docs/images/shared-workflow.png)

[목록 공유 예제](examples/shared-library.json)에서는 두 노드가 같은 라이브러리에서 카메라와 조명 프롬프트를 각각 선택합니다. 서로 다른 워크플로·탭·사용자 간 자동 동기화는 지원하지 않습니다. 다른 작업으로 옮길 때는 JSON 내보내기·가져오기를 사용합니다. 가져오기는 기존 목록을 교체하지 않고 항목을 추가합니다.

## 알아둘 동작

- 출력은 **현재 편집기에 적힌 텍스트**입니다. 저장하지 않은 수정도 출력에 반영됩니다.
- 라이브러리는 워크플로 JSON에 들어갑니다. 같은 워크플로의 노드들은 저장 목록을 공유하고, 선택과 미저장 편집은 각자 유지합니다.
- 정렬은 목록의 표시 순서를 바꾸며 노드별 설정으로 워크플로에 저장됩니다.
- 워크플로와 JSON 내보내기에는 선택한 프롬프트 외에도 전체 목록, 편집 초안, 마지막 삭제 항목이 포함될 수 있습니다. 공유 전에 내용을 확인하세요. 워크플로 메타데이터를 담는 생성 파일에도 포함될 수 있습니다.
- 문자열을 그대로 전달하는 노드입니다. 프롬프트 자동 생성, 와일드카드 전개, 여러 문자열의 자동 결합, 특정 모델 문법 변환은 하지 않습니다.

```sh
python -m unittest discover -s tests -p "test_*.py"
node --test tests/library.test.js
node --check web/prompt_selector.js
```
